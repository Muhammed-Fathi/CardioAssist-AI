## 5. Bounded document and OCR design
Use project-generated fabricated, visibly watermarked fixed-template English reports, not real medical scans. Include five fields with explicit units/codes and a separate report for unrelated lab values if useful. Accept PDF and selected image formats with strict size/page/pixel/count limits (propose PDF/PNG/JPEG, <=5 MiB per file, <=3 pages and bounded pixels; freeze exact limits after implementation feasibility review). Local Tesseract-class OCR, PDF text extraction for text PDFs and actual raster OCR for scanned PDFs/images, no cloud or paid API. Pin and review dependencies/version, Windows setup and license. OCR is real extraction, not hardcoded autofill; no model-generated interpretation or guessed field. Explicit allowed template/version/labels, anchored parsing, duplicate/conflict detection, strict unit/category checks, missing/low-confidence → editable blank or review-required; no automatic patient confirmation or inference. Raw extraction, original file hash, page/region, engine/version, confidence (nullable if unavailable), edited value, actor/time and confirmation retained. Manual entry remains first-class; do not relabel OCR-derived value as manual to bypass gates.
F14/F15 require clinician verification for clinical feature sets; patient confirmation is not clinician verification. Default OCR values remain unverified and ineligible for existing Track A. To preserve intended pre-review demo without violating existing rule, propose a narrow independently approved fabricated-demo intake contract: patient-confirmed values from known synthetic template, explicit separate source kind distinguishing manual/OCR origin, server-assigned provenance, no claim of verified clinical data. If approval is denied, retain attachment/autofill demo and separately report blocked OCR-to-inference route; owner must resolve delivery scope. No automatic ingestion from unrelated labs or Track B, even after doctor verification. Clinician review sees original reports and provenance and may record verification/rejection, never silently mutate an already published snapshot.
