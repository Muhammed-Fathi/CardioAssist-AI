## Adjudication, not activation

- **S-9:** DM, HTN, Current Smoker, EX-Smoker, FH, Typical Chest Pain: numeric 0/1 **representation** locally audited; provisional 0=absent, 1=present direction supported only by secondary Table 1. No owner codebook found. No recoding or change to dictionary 1.1.0; obtain owner codebook/author clarification or a separately scoped, explicitly reviewed scientific decision before treating direction as established.
- **BP / PR:** BP is a single numeric value registered as mmHg; **systolic vs diastolic vs other, posture/resting conditions, device, timing and operator unknown**. PR is numeric registered as beats/minute; some secondary descriptions use “ppm”; pulse-rate intention is plausible, **unit notation, device, conditions and timing unverified**. Source owner/collection form needed. Ranges do not settle semantics.
- **Chest pain:** Typical (numeric) versus Atypical/Nonanginal/Exertional CP (textual) remain separate as delivered. Mutually exclusive vs overlapping elicitation and exertional relationship unknown. Do not collapse, force exclusivity or interpret contradictory patterns as proof. Symptoms may be documented retrospectively after cath.
- **U-6:** No timestamped field-level source documentation establishing the pre-angiography decision moment. Demographics/history are generally obtainable before catheterization, but retrospective recording and post-result coding cannot be excluded. Demand owner acquisition protocol/data dictionary or separately reviewed bounded policy with explicit limitation; do not mark any field VERIFIED from plausibility alone.
- **Target/source independence:** UCI-412's ≥50% angiographic CAD is cross-sectional, not 30-day risk. UCI-45 Cleveland/Hungary documentation uses >50%; exact-boundary equivalence unresolved. UCI-411 extends the same 303 patients, cannot count as independent or additive samples. No cross-source comparison or new evaluation performed.
- **Status and blockers:** All 16 are below VERIFIED, six binary directions S-9 unresolved, BP/PR semantics and chest-pain relation unknown, U-6 all fields, and target threshold H-01 unresolved for harmonization. D-046 read-only audit cannot authorize fitting. D-048 remains proposed in checked-in governance; local M3a signed manifest/provenance/protected source and exact signed protocol bindings must be independently checked by the existing Windows preflight. **A scientific register cannot override any of those gates.** No real-data fitting, clinical scoring or approval is implied by AI-8R engineering.

## Windows maintainer handoff (clean *isolated* checkout; no local protected files copied)

From an existing checkout on native Windows with GitHub CLI (`gh`) installed, create a **detached worktree at the live PR #74 head** and keep the venv **outside** every repository/worktree. Stop on any unexpected status; never copy local manifests, workbooks, keys, or other protected files. The paths below must be on a locally controlled NTFS volume with appropriate owner-only protection; they are not a place for patient data.

```powershell
$ErrorActionPreference = 'Stop'
$repo = (Get-Location).Path
$root = Join-Path $env:LOCALAPPDATA 'CardioAssist_AI'
$worktree = Join-Path $root 'AI8R_PR74_Worktree'
$venv = Join-Path $root 'AI8R_Test_Venv'
if (Test-Path $worktree) { throw 'Use a new clean isolated worktree path; do not reuse an existing checkout.' }
New-Item -ItemType Directory -Force $root | Out-Null
git -C $repo fetch origin refs/pull/74/head
if ($LASTEXITCODE -ne 0) { throw 'PR fetch failed' }
$prHead = (gh pr view 74 --json headRefOid --jq '.headRefOid').Trim()
if ($LASTEXITCODE -ne 0) { throw 'PR head lookup failed' }
$fetchedHead = (git -C $repo rev-parse FETCH_HEAD).Trim()
if ($fetchedHead -ne $prHead) { throw 'PR head moved during fetch; retry from scratch' }
git -C $repo worktree add --detach $worktree $prHead
if ($LASTEXITCODE -ne 0) { throw 'Isolated worktree creation failed' }
Set-Location $worktree
if ((git rev-parse HEAD).Trim() -ne $prHead) { throw 'Worktree does not match exact PR head' }
if (git status --porcelain --untracked-files=all) { throw 'Worktree is not clean; do not run preflight' }
py -3.12 -m venv $venv  # external; .venv-uci412 inside the worktree is NOT ignored
if ($LASTEXITCODE -ne 0) { throw 'Python venv creation failed' }
$python = Join-Path $venv 'Scripts\python.exe'
& $python -m pip install -r research/uci412/requirements.txt -r backend/requirements-dev.txt
if ($LASTEXITCODE -ne 0) { throw 'Dependency installation failed' }
& $python -m pip check
if ($LASTEXITCODE -ne 0) { throw 'Dependency check failed' }
& $python -m pytest -W error -q tests/uci412 tests/experiments
if ($LASTEXITCODE -ne 0) { throw 'Targeted tests failed' }
& $python -m pytest -W error -q
if ($LASTEXITCODE -ne 0) { throw 'Full tests failed' }
if (git status --porcelain --untracked-files=all) { throw 'Worktree became dirty' }
& $python -m research.uci412 readiness
$readinessExit = $LASTEXITCODE  # expect 2: SCIENTIFIC_HOLD; local_gate REJECTED_*
if ($readinessExit -ne 2) { throw 'Unexpected readiness exit; investigate without running training' }
& $python -m research.uci412 preflight
$preflightExit = $LASTEXITCODE  # expect 2: FAIL CLOSED without separate local authorization
if ($preflightExit -ne 2) { throw 'Unexpected preflight exit; do not run training' }
& $python scripts/verify_sources.py
if ($LASTEXITCODE -ne 0) { throw 'Source verification failed' }
git diff --check
if ($LASTEXITCODE -ne 0) { throw 'Diff check failed' }
if (git status --porcelain --untracked-files=all) { throw 'Worktree became dirty' }
$prHead; $readinessExit; $preflightExit
```
