# Pinned dependencies for the CardioAssist AI contract tests (M1a.1).
#
# The contract tests are intentionally tiny and offline: they only read the
# committed contract files and the committed fixture pack. No model, no
# dataset, no database, no cloud service and no account is required.
#
#   python -m venv .venv
#   . .venv/bin/activate            # Windows: .venv\Scripts\activate
#   pip install -r tests/contracts/requirements.txt
#   python -m pytest tests/contracts -q
#
# All packages are pure-Python and run on free GitHub Actions runners at $0.
# The five direct dependencies are pinned, and their transitive resolutions are
# pinned as well (resolved on 2026-10-16) so that a CI run is reproducible.
